# แผนที่ 3 มิติ โรงเรียนธัญรัตน์

แผนที่ 3 มิติแบบหน้าเว็บ (Three.js) ของโรงเรียนธัญรัตน์ หมุน ซูม และคลิกอาคารเพื่อดูผังแต่ละชั้นได้ ใช้งานบนมือถือได้

## ไฟล์

| ไฟล์ | เนื้อหา |
|---|---|
| `index.html` | แผนที่หลัก งานแข่งขันหุ่นยนต์และคอมพิวเตอร์ (จุดลงทะเบียน สนามแข่ง ผังห้อง) |
| `front.html` | แผนที่หลัก + ลานจอดรถหน้าโรงเรียน สนามฟุตบอล ถ.รังสิต–นครนายก (305) และคลองรังสิต |
| `evac.html` | แผนเผชิญเหตุ: เส้นทางหนีไฟอาคาร 1–8 จุดรวมพล และการจำลองไฟไหม้ |
| `videos/evac_building_1.mp4` … `evac_building_8.mp4` | วิดีโอจำลองการอพยพแยกรายอาคาร (เล่นเร็ว ×2) |

ทุกไฟล์ HTML เป็นไฟล์เดียวจบ เปิดในเบราว์เซอร์ได้เลย (ต้องต่ออินเทอร์เน็ตเพื่อโหลด Three.js จาก CDN)
